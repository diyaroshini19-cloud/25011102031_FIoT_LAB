## Source references and hardware assumptions

The original CAT5 and CAT7 manuals specify experiment behavior but omit some implementation wiring. For CAT5C, the default mapping is P1.3/P1.2/P1.1/P1.0 to the four driver phases and active-low speed/direction buttons on P3.0/P3.1. Use an external ULN2003 or suitable transistor driver, external motor power, and common ground; never drive coils directly from MCU pins. For CAT7C, the default keypad matrix is rows P1.0–P1.3 and columns P1.4–P1.7, active low. These defaults are documented in each README and are not claims about the original lab board. Adjust firmware if the actual wiring differs.

The CAT5 phase pattern sent on P1.3..P1.0 is `1000, 0100, 0010, 0001`. The speed button cycles 100 → 50 → 10 → 100 ms per step; the direction button reverses rotation. CAT7's LCD remains on RS=P3.3, EN=P3.2, D4–D7=P3.4–P3.7, with RW grounded.
