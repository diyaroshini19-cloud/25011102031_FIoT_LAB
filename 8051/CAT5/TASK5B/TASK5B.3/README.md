# Week 5 — Pulse and burst patterns

## Objective and platform
Demonstrate square, variable-duty, narrow-pulse and burst output patterns with an AT89S52.

## Hardware
Output is P1.1, established by the supplied CAT5 category pin table. Observe with a logic analyzer or oscilloscope.

## Implementation
Timer 0 provides an approximately 50 microsecond time step. Firmware cycles through four patterns: 1 kHz square wave, variable duty ramp, short periodic pulses, and a burst followed by a quiet interval. Automatic cycling avoids inventing an undocumented mode-select pin.

## Build and status
Open `TASK5B.3.uvproj` in Keil or use `sdcc -mmcs51 --model-small --out-fmt-ihx TASK5B.3.c -o Objects/TASK5B.3.ihx`. The included Intel HEX was generated by SDCC 4.6.0. Timing and waveform fidelity need physical scope validation.
