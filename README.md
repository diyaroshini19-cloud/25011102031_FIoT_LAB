# FOUNDATIONS OF IoT

A collection of laboratory experiments completed as part of the **Foundations of Internet of Things (IoT)** course.

This repository contains practical implementations using **8051 and STM32 microcontrollers**, including source code, hardware configurations, circuit diagrams and experiment documentation.

## Platforms and Tools

| Platform | Development Environment |
|---|---|
| 8051 Microcontroller | Keil µVision |
| STM32 Microcontroller | STM32CubeIDE |
| Programming Language | Embedded C |
| Hardware Interfacing | Sensors and peripherals |

## Experiment Documentation

Each experiment folder contains:

- **README.md** – Experiment details, aim, hardware setup, task description, core logic and inference.
- **Circuit Diagram** – Hardware connections and interfacing details.
- **Source Code** – Program files and relevant project configurations.

## Microcontroller Platforms

### 8051
Experiments involving 8051 microcontroller programming, peripheral interfacing and embedded system fundamentals.

### STM32
Experiments involving STM32 microcontroller programming, GPIO, timers, communication protocols and sensor interfacing.
